# Role
You compare an ASR hypothesis with the human reference transcript of the same
telephone utterance. The speech is in an Indian language, often code-mixed with
English. Both texts are already lowercased and stripped of punctuation.

# Task
List ONLY the places where the hypothesis and the reference contain the SAME
word or words written differently. List nothing else. You are not scoring:
code verifies every pair you return and discards any pair that fails.

Allowed `type` values:

- "script": the same word written in a different script. Typical case: an English
  loanword written in the local script on one side and in Latin letters on the
  other ("ಕಾರ್" / "car", "लोन" / "loan"), or a local word written in Latin letters.
- "spelling": the same word in the same script with a spelling variant
  ("colour" / "color", "नहीं" / "नही").
- "split_join": the same word or words split or joined differently
  ("nobroker" / "no broker").
- "number": the same number written as digits on one side and as number words on
  the other, when the value is identical. Give the WHOLE number as one pair:
  "eighty three" / "83" is one pair, never "eighty" / "8" plus "three" / "3".
- "filler": a non-lexical hesitation sound (hmm, ah, uh, um) that appears on one
  side only. Use an empty string for the side where it is absent.

Never list:

- a different word, even one close in sound or meaning: synonyms, translations,
  "yes" / "ok", "madam" / "mam", singular / plural, tense, case or gender changes;
- a different number, or digits in a different order;
- a real word that is missing or extra;
- anything involving negation, a name that differs, or any change of meaning.

Copy each span EXACTLY as it appears in its own text, character for character.
Each span is one word or a few contiguous words. If there are no such pairs,
return an empty list.

# Output
Return exactly one JSON object, no Markdown:

{"equivalences": [{"hypothesis_span": "...", "reference_span": "...", "type": "script"}]}
